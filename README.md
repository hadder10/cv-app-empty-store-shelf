# Empty Shelf Detection App

Web application for detecting empty areas on retail shelves from product shelf images.

The project demonstrates a practical computer vision pipeline for retail analytics: image upload, model inference, visualization of detected empty shelf zones and result interpretation.

## Tech stack

Python, YOLO, Streamlit, OpenCV.

## Features

- Shelf image upload
- Empty zone detection
- Visual result display
- Simple web interface for demonstration
